2026-10-17 实测结论

iframe 去横幅方案不可用

Safari 顶部的 WPS「在 App 中打开」横幅是系统级 Universal Link， 不是网页 DOM；网页 CSS / JS 无法移除。

  • 原因 1：/l/* 在 WPS App 的 AASA 关联列表里，Safari 会直接显示原生横幅。
  • 原因 2：把文档放进 iframe，会被 WPS SSO 跳到 account.wps.cn；登录型文档最终停在空白页。
  • 原因 3：/office/s/ 虽避开 Universal Link，但 kdocs 用 shareId 调 /open/et 报 InvalidArgument，PDF 渲染不出来。
  • 原因 4：PDF 渲染完成后用 history.replaceState 改 URL，Safari 也不会撤掉已经出现的横幅（iPad 实测）。
